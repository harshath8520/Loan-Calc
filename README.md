# Credit Card and Loan Tracker

A simple, mobile-first web application for tracking credit cards and loans with beautiful shadcn-inspired design.

## Quick Start

1. Open `index.html` in a modern web browser
2. No installation or build process required - it's pure HTML, CSS, and JavaScript
3. All data is stored locally in your browser using localStorage

## Features

- **Dashboard**: Overview of total debt, credit utilization, and recent activity
- **Cards & Loans Management**: Add, edit, and delete credit cards and loans
- **Payment Tracking**: Record payments and view payment history
- **Debt Payoff Calculator**: Calculate payoff timelines and interest costs
- **Reminders**: Set reminders for payment due dates
- **Analytics**: Visual charts showing debt breakdown, payment distribution, and trends

## Usage

### Adding a Credit Card
1. Click "Add Card" on the dashboard or navigate to Cards & Loans
2. Fill in the card details (name, balance, limit, interest rate, etc.)
3. Optionally add a category and tags for organization
4. Click "Save"

### Adding a Loan
1. Click "Add Loan" on the dashboard or navigate to Cards & Loans
2. Fill in the loan details (name, principal, balance, interest rate, etc.)
3. Optionally add a category and tags
4. Click "Save"

### Recording a Payment
1. Click "Make Payment" on the dashboard or navigate to Payments
2. Select the card or loan
3. Enter the payment amount and date
4. Add optional notes
5. Click "Save"

### Using the Calculator
1. Navigate to Calculator
2. Select a debt (card or loan)
3. Choose payment strategy (monthly payment or target date)
4. Enter the amount or target date
5. Click "Calculate" to see payoff timeline and interest costs

## Data Storage

All data is stored locally in your browser's localStorage. No data is sent to any server. To clear all data, use your browser's developer tools to clear localStorage.

## Browser Support

Works in all modern browsers that support:
- ES6 JavaScript
- CSS Grid and Flexbox
- localStorage API

## Technologies

- Pure HTML, CSS, and JavaScript (no frameworks)
- Chart.js for data visualization
- Shadcn-inspired design system
